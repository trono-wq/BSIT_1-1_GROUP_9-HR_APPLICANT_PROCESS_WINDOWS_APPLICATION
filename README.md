AI Usage in This Project
During the development of my HR Staff module, I used AI as a learning assistant and coding guide throughout the project.
I used AI assistance in the following ways:

Asked for explanations on how C# Windows Forms works, especially connecting forms to a MySQL database
Asked for guidance on setting up the project structure and following our team's naming conventions
When I encountered errors or bugs, I described the problem and asked for help understanding what went wrong and how to fix it
Asked for code examples and explanations when I was unsure how to implement certain features like status history recording and database queries

However, all final decisions on implementation, form design, and logic flow were made by me. I manually typed, reviewed, and tested every part of the code to make sure I understood what each line does. AI was used as a reference and guide — similar to how one would use documentation or ask a senior developer for advice — not as a replacement for my own work and understanding.
This project helped me learn C# Windows Forms, MySQL database connection, and Git version control from scratch.
